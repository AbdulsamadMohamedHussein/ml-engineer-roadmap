# My 2-Year Machine Learning Engineer Roadmap

Documenting my journey from AI student to Machine Learning Engineer, in public.

- **Goal:** Get hired as a Machine Learning Engineer
- **Started:** November 2026
- **Target:** October 2028
- **Pace:** about 8-10 hours a week on top of my AI degree
- **Rule:** build more than I watch, and commit every week

## How this repo works

| Folder | What goes in it |
|--------|-----------------|
| `journal/` | One short log per month: what I did, what was hard, what's next |
| `notes/` | My notes by topic (math, ML, deep learning, MLOps, LLMs) |
| `projects/` | Index of every project, with links to the full repos |
| `resources/` | Courses, books and papers, with status |

- [ ] SQL basics

### Months 4-6: Math and classical ML (Feb - Apr 2027)
- [ ] Linear algebra
- [ ] Probability and statistics
- [ ] Basic calculus

### Months 7-9: Deep learning (May - Jul 2027)
- [ ] Neural network fundamentals: backpropagation, optimizers, regularization
- [ ] PyTorch
- [ ] CNNs for images
- [ ] Intro to sequence models and transformers
- [ ] **Project 2:** image or text classifier, trained and evaluated properly

### Months 10-12: Kaggle and applying skills (Aug - Oct 2027)
- [ ] Kaggle competition #1
- [ ] Kaggle competition #2
- [ ] Feature engineering and model debugging

## Year 2: Production skills and job readiness (Nov 2027 - Oct 2028)

### Months 13-15: Deployment (Nov 2027 - Jan 2028)
- [ ] Wrap a model in an API with FastAPI
- [ ] Docker basics
- [ ] Deploy to a cloud platform (AWS, GCP or Azure)
- [ ] **Project 3:** deployed model with a live URL

### Months 16-18: MLOps and modern AI (Feb - Apr 2028)
- [ ] Experiment tracking (MLflow or Weights & Biases)
- [ ] Data pipelines, testing, model monitoring
- [ ] LLMs: embeddings, RAG, fine-tuning basics, evaluation
- [ ] **Project 4:** LLM-powered app (for example, document Q&A)

### Months 19-21: Specialize and go deeper (May - Jul 2028)
- [ ] Pick a specialization: NLP/LLMs, computer vision, recommenders or time series
- [ ] Reproduce one research paper
- [ ] Contribute to an open-source ML library
- [ ] **Capstone project** in my specialization

### Months 22-24: Get hired (Aug - Oct 2028)
- [ ] Polish GitHub: 3-4 strong projects with READMEs, results and live links
- [ ] One-page resume focused on projects and impact
- [ ] Practice coding and ML interviews
- [ ] Apply widely and network
