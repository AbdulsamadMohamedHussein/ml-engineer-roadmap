## Key concepts
| Concept | Use | Example |
|:--|:--|:--|
| dict | Count or look things up | `counts[word] = counts.get(word, 0) + 1` |
| set | Remove duplicates | `set([3, 1, 3])` |
| list comprehension | Build a list in one line | `[n*n for n in nums if n % 2 == 0]` |
| `.items()` | Loop over keys and values | `for k, v in d.items():` |
